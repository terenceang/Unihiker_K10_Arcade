## Verification Instructions

To verify ROMs against these hashes:

### Windows PowerShell
```powershell
# Single file
$hash = (Get-FileHash "path\to\rom.bin" -Algorithm SHA256).Hash
Write-Output $hash

# All ROMs in a folder
Get-ChildItem -Path "path\to\roms" -File | ForEach-Object {
    $hash = (Get-FileHash $_.FullName -Algorithm SHA256).Hash
    Write-Output "$($_.Name) : $hash"
}
```

### Linux/macOS
```bash
# Single file
sha256sum path/to/rom.bin

# All ROMs in a directory
sha256sum path/to/roms/*
```

### MAME Verification
If you have MAME installed:
```bash
mame -verifyroms galaga pacman dkong frogger
```

## Notes

- All ROMs are compiled into the firmware as C header arrays
- ROM conversion tools are located in `romconv/`
- To disable a game, comment out its `#define ENABLE_<GAME>` in [arcade_core/config.h](../main/arcade_core/config.h)
- Audio samples are located in `samples/` directory
